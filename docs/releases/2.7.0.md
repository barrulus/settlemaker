# 2.7.0 — biome artwork in the village and city generators

Released 2026-09-11. Includes the measured-water, river, henge-reservation and
woodland behavior from 2.6.0. URL payload version remains 1, Scene version 2 and
GeoJSON schema 4; the generator version in exported metadata is now 2.7.0.

The default asset set now selects native city or rural buildings, religious and
defensive forms, varied flora and field textures for all five biomes. Walls
follow planned boundaries with real gate gaps, bridges follow surveyed crossings,
and requested and incidental village henges use the enhanced varied drawings.
Updated crown measurements also apply to the newer woodland clearance index.
Oblique growth probes measure narrow streams across their banks so a long
diagonal crossing cannot incorrectly squeeze the village into a coastal strip.

Palace/castle pieces use existing ward sites. Complete compound presets remain
available as authoring assets; automatic aggregate site planning is not added.
Field textures follow real parcel polygons, with irrigation details where needed.

See [artwork integration](../artwork-integration.md) for selection and placement
contracts, source regeneration and the eleven-map public-API review gallery.
No new URL option, runtime download or FMG sender change is needed.

## Web handoff

Pin settlemaker-web's `settlemaker/` submodule to this release and build the normal
library/site artifacts. The new SVG bodies are embedded in the browser bundle;
production does not need to fetch the artwork galleries. Keep the library as the
separate `/lib/settlemaker.js` artifact. Existing water diagnostics and download
flows remain in place. Reverting the web pin commit restores the previous release.

The web repository's matching release note records the exact generator revision
and final build/test results.

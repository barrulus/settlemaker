# 3.0.1 — current documentation and generated examples

The npm README and public documentation now describe the 3.0.x library and its
portable skin system. The README includes regenerated PNG/SVG examples from the
current public API, with release-pinned links that work on npm and GitHub.

New getting-started, API, GeoJSON, gallery and development guides replace the
outdated entry-point examples and fragmented contract guidance. The URL and city
scene guides document current options, coordinate/engine differences, rendering
limits and separate website deployment. Schema v3 is clearly historical.

The examples cover five default artwork biomes in both planners and Copperline.
Documentation checks run the README examples, typecheck snippets and check links,
anchors and gallery provenance. Public docs and gallery files ship in the package.

Generation algorithms and artwork are unchanged from 3.0.0. Exported generator
metadata reports 3.0.1; GeoJSON schema 4, Scene 2, URL payload 1, skin format 1 and
water context 1 remain unchanged.

# Gallery

These maps were generated with SettleMaker 3.0.1 through the public
`generateSettlement` API. PNG previews and full SVGs come from the same output.
The gallery covers all five built-in artwork biomes in both engines, plus Copperline.

[Exact inputs and seeds](examples/gallery/fixtures.json) · [Regenerate the gallery](development.md#documentation-checks)

Hosted preview links carry the saved inputs; the website's deployed generator may
differ from this package version. Skins are loaded by the library API, so the
Copperline examples link to their SVGs rather than an unsupported skin URL.
